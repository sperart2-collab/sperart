# SPERART content checklist (fill these in the Admin, no code needed)

Edit content (Admin > Edit content)
- Hero headline, subtitle, button
- Story, Mission, Vision (official wording from SPERART)
- Leadership: Name | Role | Photo link (upload photos in Media first)
- Membership types and REAL prices (Individual, Student, Group, Organization)
- Contact details and WhatsApp number

Add content
- Media: upload performance videos, photos, audio; Rename each with a proper title
- Academy: first beginner rudiments and lessons (video from Media)
- News: first announcement
- Events: next workshop or performance
- Recognition: awards, scholarships, featured artists
- Library: articles, research, resources

Ask the client for: official mission and vision, full leadership list with photos,
membership types and prices, photos of the studio, upcoming event dates, award list.

Email alerts: add RESEND_API_KEY and ADMIN_NOTIFY_EMAIL in Netlify > Environment variables.
